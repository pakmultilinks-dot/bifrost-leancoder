# Task 1: Add a pure function

Add a pure function `median` to `mathutil.py`, with a docstring.

- `median([1, 3, 2])` returns 2
- `median([1, 2, 3, 4])` returns 2.5, the average of the two middle values
- `median([5])` returns 5
- `median([])` raises ValueError with a clear message
- The function must have a docstring

Do not change the existing `add` and `subtract` functions.
