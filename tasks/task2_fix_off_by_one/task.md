# Task 2: Fix an off-by-one bug

The function `total_upto` in `counter.py` is supposed to return
1 + 2 + ... + n, but it returns the wrong total. Find the off-by-one
bug in the loop and fix it.

- `total_upto(5)` must return 15
- `total_upto(1)` must return 1
- `total_upto(0)` must return 0

Do not change the function signature or its docstring.
